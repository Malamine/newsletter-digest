Politique de confidentialité — Newsletter Digest

Dernière mise à jour : 28 septembre 2026

Newsletter Digest est un outil personnel, développé et utilisé par une seule personne (son créateur) pour résumer automatiquement ses propres newsletters. Il n'est pas distribué au grand public, ne comporte pas de création de compte, et ne collecte de données que pour son propre usage.

Quelles données sont consultées

L'application se connecte à une boîte Gmail via l'API Gmail (accès en lecture seule, permission gmail.readonly) pour lire uniquement les emails portant le label « NEWSLETTER ». Aucun autre email n'est consulté, envoyé, modifié ou supprimé. L'application ne peut pas écrire dans la boîte mail ni agir en son nom.

Comment ces données sont utilisées

  • Le contenu des emails du label NEWSLETTER est envoyé à l'API Gemini (Google) pour être trié, résumé et transformé en questions de quiz.
  • Les résultats (titres, résumés, scores de pertinence, questions de quiz) sont stockés dans une base de données Firestore privée, hébergée sur un projet Google Cloud appartenant au créateur de l'application.
  • Aucune donnée n'est vendue, partagée avec des tiers à des fins commerciales, ou utilisée à des fins publicitaires.

Autres données stockées

  • Réponses au quiz : auto-évaluations ("su" / "pas su") liées aux questions générées, pour suivre la progression d'apprentissage.
  • Abonnement aux notifications : si les notifications push sont activées, un identifiant d'abonnement technique (endpoint + clés de chiffrement, standard Web Push) est stocké pour pouvoir envoyer des rappels.
  • Statut de lecture : quels articles du digest ont été marqués comme lus.

Conservation et suppression

Les données sont conservées indéfiniment dans la base Firestore privée du projet, dans le seul but de constituer un historique utile au fonctionnement de l'application (éviter les répétitions, mesurer la progression). Étant un outil strictement personnel, la suppression de données se fait directement par le créateur de l'application via la console Google Cloud.

Tiers impliqués

Les seuls services tiers utilisés sont des services d'infrastructure Google : Gmail API (lecture des emails), Gemini API (traitement du texte), Google Cloud Run et Firestore (hébergement et stockage). Ces services traitent les données dans le cadre de leurs propres conditions d'utilisation en tant que sous-traitants techniques ; aucune donnée n'est transmise à d'autres tiers.

Contact

Cette application n'ayant qu'un seul utilisateur (son créateur), les questions relatives à cette politique peuvent être adressées via le dépôt du projet : github.com/Malamine/newsletter-digest.
